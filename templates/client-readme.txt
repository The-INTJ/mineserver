  * Minecraft Java Edition {{minecraftVersion}}
  * Fabric Loader (any recent version; the server runs {{loaderVersion}})
    Install from https://fabricmc.net/use/installer/ and pick {{minecraftVersion}}.

Install
  1. Press Win+R, type %APPDATA%\.minecraft\mods and press Enter
     (macOS: ~/Library/Application Support/minecraft/mods).
  2. Remove any mods for other Minecraft versions.
  3. Copy every .jar from the mods/ folder of this zip into that folder.
  4. Launch Minecraft with the Fabric {{minecraftVersion}} profile.
  5. Multiplayer > Add Server > address: {{serverAddress}}
